## String Calculator 요구사항
- [X] 구분자를 기준으로 분리한 각 숫자의 합을 반환한다. 
  - [x] 쉼표(,) 또는 콜론 (:)을 구분자로 가지는 문자열을 전달한다.
  - [x] 커스텀 구분자를 지정할 수 있다. 문자열 앞 부분의 // 와 \n 사이의 문자를 사용
  - [x] 구분자는 혼합하여 사용할 수 있다. ex) "1,2:3” => 6, "//;\n1,2;3" => 6
- [X] 예외 처리 
  - [X] 숫자 이외의 값을 전달하는 경우 RuntimeException 예외를 던진다.
  - [X] 공백은 숫자가 아닌 값이므로 RuntimeException 예외를 던진다.  
  - [X] 음수를 전달하는 경우 RuntimeException 예외를 던진다.
