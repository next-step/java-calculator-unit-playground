# java-calculator

## 1단계 계산기 요구사항

- 인자 2개를 받아 사칙연산을 할 수 있는 계산기를 구현한다.
- 사칙연산과 매칭되는 4개의 메서드를 제공한다.
- 계산된 결과는 정수를 반환한다.
- 메인 메서드는 만들지 않는다.
- 0으로 나누었을 경우 에러 메세지를 띄워준다.
  - 두번째 인자가 0이라면 `0으로 나눌 수 없습니다.`를 띄워준다.

## 2단계 계산기 요구사항

- 문자열로 이루어진 수식이 들어오는 경우 계산이 이루어진다.
  - 2개의 인자와 1개의 연산자가 들어온다.

## 3단계 계산기

- 숫자와 구분자가 여러개 들어와도 형식만 맞다면 계산이 가능해야한다.
- 쉼표(,), 콜론(:)가 구분자로 들어오는 경우 +처럼 계산한다.
- “//”와 “\n” 사이에 위치하는 문자를 커스텀 구분자로 사용할 수 있게 구현한다.
  - 커스텀 구분자는 1개만 지정 가능하다.
  - 커스텀 구분자를 '+'처럼 사용할 수 있게 구현한다.
- 숫자 이외의 값이나 음수가 전달되는 경우 `RuntimeException` 를 발생시킨다.
