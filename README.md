## 🧮 계산기 미션

### 📋 기능 구현 목록

### 1단계, 2단계 - 초간단 계산기

- [x] 인자 2개를 받아 사칙연산 계산기 구현.
    - [x] ➕ 덧셈
    - [x] ➖ 뺄셈
    - [x] ✖️ 곱셈
    - [x] ➗ 나눗셈

### 3단계 - 문자열 계산기 구현

[ 기본 ]

- 쉼표(`,`) 또는 콜론(`:`)을 구분자로 가지는 문자열 -> 구분자를 기준으로 **분리** -> 각 숫자의 **합**을 반환

[ 커스텀 ]

- 앞의 기본 구분자(쉼표, 콜론)외에 커스텀 구분자 지정
- 커스텀 구분자는 문자열 앞부분의 `//`와 `\n` 사이에 위치

[ 공통 ]

- `RuntimeException` 예외
    - 숫자 이외의 값 또는 음수 전달
    - 잘못된 커스텀 구분자 형식

- [x] 구분자 기준 분리
- [ ] 숫자 이외의 값 또는 음수 전달 시 예외 발생
- [ ] 합 계산
