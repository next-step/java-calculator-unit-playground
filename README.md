# java-calculator

## [1] 초간단 계산기 구현

- 요구사항
  - [x] 계산기는 인자 2개를 받아 사칙연산을 한다.
  - [x] 사칙연산과 매칭되는 4개의 메서드를 제공한다.
  - [x] 계산 결과는 정수를 반환한다.
  - [x] 메인 메서드는 만들지 않는다.

## [2] 초간단 계산기 테스트

- 요구사항
  - [x] 구현된 초간단 계산기 동작을 Junit5로 Unit Test 한다.
  - [x] 메인 메서드는 만들지 않는다.

## [3] 문자열 계산기 구현
  
  - 요구사항
    - [ ] 쉼표(,) 또는 콜론(;)을 기본 구분자로 가지는 문자열을 입력받는다.
      - [ ] 이 두 가지 기본 구분자 외에 커스텀 구분자를 지정할 수 있다.
      - [ ] 문자열 앞부분의 "//"와 "\n" 사이에 위치한 문자를 커스텀 구분자로 본다.
    - [ ] 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
    - [ ] 입력된 값에 숫자 이외의 값 또는 음수를 전달하는 경우 RuntimeException 예외를 throw 한다.
    - [ ] 구현된 문자열 계산기 동작을 Junit5로 unit test 한다.
    - [ ] 메인 메서드는 만들지 않는다.
